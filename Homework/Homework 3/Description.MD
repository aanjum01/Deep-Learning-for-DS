# Homework — Optimization, Regularization & Activation Functions

## Description

### Dataset & Model

**MNIST** — Implement a neural network using **Python + NumPy/PyTorch**.

## 1. Optimization

Train the same model with:

- Batch Gradient Descent
- SGD
- Momentum
- Adam

**Task:** Plot **Training Loss vs. Epoch** and identify which optimizer converges fastest.

## 2. Regularization

Compare:

- No Regularization
- L2
- L1
- Dropout

**Task:** Compare **Training/Validation Loss & Accuracy** and analyze generalization.

## 3. Activation Functions

Compare:

- ReLU
- Sigmoid
- Tanh

**Task:** Compare **loss, accuracy, and convergence** while keeping the architecture and optimizer fixed.

## Analysis

Answer the following questions:

1. Which optimizer converged fastest?
2. How did L1/L2 affect the weights?
3. How did dropout affect training vs. validation?
4. Which activation function performed differently and why?
5. Which configuration generalized best, and why?
